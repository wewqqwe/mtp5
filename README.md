## Задания варианта 3

калькулятор с проверкой ввода; вкладки Notebook и журнал операций; цветная панель; кликер (раунд, рекорд, сброс, автоклик); GUI SQLite со списком, добавлением, правкой и удалением

Окно собирается на Tkinter и `ttk`. Расчёты, вкладки, цвет, кликер и таблица SQLite живут в `logic.py` и проверяются без экрана. `ui.py` рисует виджеты и вызывает эти функции. Ошибка ввода калькулятора пишется в метку результата. Список goods читается при старте и после каждой операции. Соединение SQLite закрывается вместе с окном.

```bash
MTP_HEADLESS=1 python main.py
python -m pytest
```

Без `MTP_HEADLESS` программа открывает окно, если Tk доступен.
