## Задания варианта 3

калькулятор; вкладки Notebook; цветная панель; кликер; GUI для SQLite

Окно собирается на Tkinter и `ttk`. Расчёты, вкладки, цвет, счёт кликов и таблица SQLite живут в `logic.py` и проверяются без экрана. `ui.py` только рисует виджеты и вызывает эти функции.

```bash
MTP_HEADLESS=1 python main.py
python -m pytest
```

Без `MTP_HEADLESS` программа открывает окно, если Tk доступен.
